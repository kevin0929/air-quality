# Fine-tune 使用手冊

## 目錄內容

- `finetune_dcrnn.py`：載入 DCRNN 預訓練權重並進行微調。
- `dcrnn_faithful.py`：DCRNN 模型架構。
- `prepare_finetune_data.py`：把整理後資料轉成 fine-tune 所需格式。
- `fetch_era5.py`、`fetch_cnemc.py`、`build_dataset.py`：下載並建立延伸資料集。
- `checkpoints_finetune/`：微調模型、報告及 baseline 指標。
- `runs_finetune/`：TensorBoard event files。
- `raw/`、`output/`：外部資料夾所附的來源資料與整理結果。

## 安裝

從專案根目錄執行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

請使用與專案相容的 Python/PyTorch 環境。下載 ERA5 時另需設定 CDS API 憑證；細節見本目錄 `Readme.md`。

## 建立訓練資料

現有外部資料包含 `output/dataset.npy` 等資料建置輸出，但 DCRNN 微調程式讀取的是 `features.npy`、`adj_mx.npy`、`scalers.pkl`、`split.pkl` 四個檔案。先確認已取得並正確配置站點清單與原始 KnowAir 資料，再依 `Readme.md` 建立/整理資料，並用 `prepare_finetune_data.py --help` 查看目前版本的實際參數。

訓練報告引用的資料目錄為 `data/processed_yrd_finetune`；外部交付資料夾沒有包含該目錄，因此要重跑訓練或評估時須先備妥資料。請確認特徵、站點順序、時間切分、正規化統計與預訓練模型一致。

## 載入最新權重

最新 checkpoint：

```text
checkpoints_finetune/dcrnn_finetuned_ft_from_5ep_v5_clean_best.pt
```

該權重是 5 epoch 預訓練模型的微調產物。不要只依檔名將它與使用另一個預訓練 checkpoint 的實驗混用；每份 JSON 報告都記錄了其 `pretrained_ckpt` 和資料路徑。

## 執行微調

先在本目錄查看 CLI 參數：

```bash
python finetune_dcrnn.py --help
```

基本命令格式如下，路徑請換成實際存在的 checkpoint 和資料：

```bash
python finetune_dcrnn.py \
  --pretrained_ckpt ../checkpoints_yrd_5ep/dcrnn_faithful_yrd_5ep_best.pt \
  --data data/processed_yrd_finetune \
  --epochs 30 \
  --exp_name my_finetune
```

訓練權重和報告預設寫入 `checkpoints_finetune/`，曲線寫入 `runs_finetune/`。若要避免覆寫既有實驗，請為每次執行指定新的 `--exp_name`。

## 開啟 TensorBoard

安裝 requirements 中的 `tensorboard` 後，在本目錄執行：

```bash
tensorboard --logdir runs_finetune --port 6006
```

接著開啟 `http://localhost:6006`。可把 `--logdir` 指向某個實驗子目錄，單獨檢視該次 run。TensorBoard event 檔案位於 `runs_finetune/<實驗名稱>/events.out.tfevents.*`。

## 評估與權重內插

`weight_interpolation.py` 可在預訓練權重與微調權重之間掃描 alpha。先用 `python weight_interpolation.py --help` 確認參數，再提供兩個 checkpoint 與相同格式的資料目錄。結果需以同一資料切分比較，避免跨實驗報告直接排名。
