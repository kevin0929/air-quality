# KnowAir-V2 原始碼說明

本文件說明 `KnowAir-V2/` 根目錄 pipeline 的主要模組與資料流。ERA5/CNEMC 延伸資料的細節列於 [`finetune/原始碼說明.md`](finetune/原始碼說明.md)。

## 專案分層

```text
原始 netCDF + 站點 metadata
          │
          ▼
preprocess_knowair.py ──► processed_<region>/ 資料產物
                                  │
              ┌───────────────────┼───────────────────┐
              ▼                   ▼                   ▼
         train_dcrnn.py     train_agcrn.py       train_gts.py / train_airphynet.py
              └───────────────────┼───────────────────┘
                                  ▼
                       checkpoint（權重與 args）
                                  │
                  test_models.py / test_gts.py
```

## 資料前處理

### `preprocess_knowair.py`

將 KnowAir-V2 netCDF 讀入 xarray，依站點 metadata 對齊節點與變數，建立地理距離/鄰接資訊與風場相關矩陣，並輸出模型資料。主要函式包含：

- `detect_variable()`：從候選名稱中辨識 netCDF 變數。
- `load_knowair_nc()`：載入原始資料並整理成站點時間序列。
- `haversine_km()`、`build_distance_matrix()`：計算站點間地理距離。
- `dist_to_adj()`、`build_wind_adj()`：由距離及風場資訊建立圖矩陣。
- `preprocess()`：串接載入、特徵處理、切分/標準化及檔案輸出。

前處理輸出是訓練程式間的資料契約。`features.npy` 的核心形狀為 `[T,N,F]`，其中 T 是時間步、N 是站點、F 是特徵。`stations.csv` 的列順序定義 N 軸，特徵順序定義 F 軸；切分和 scaler 則需與資料及 checkpoint 一致。

## 模型定義

### `dcrnn_faithful.py`

定義擴散卷積 GRU cell 與 DCRNN Seq2Seq encoder-decoder。圖的正反向 random walk supports 用於空間擴散，decoder 自迴歸預測單一目標 channel。`forward()` 可以接受推論時的 `pred_len` 覆寫，但延長解碼步數不等於經長時距訓練；超出訓練 horizon 的誤差可能累積。

### `agcrn_faithful.py`

定義 AGCRN 的自適應圖卷積及循環預測器。模型從可學習節點嵌入生成自適應鄰接與節點專屬參數，主要預測網路不依賴前處理提供的固定 `adj_mx`。

### `gts_faithful.py`

定義 GTS 圖結構學習與預測模型。特徵抽取器由訓練期序列形成節點嵌入，link predictor 產生節點對連結分數，Gumbel-Softmax 使離散圖可參與反向傳播；預測器使用 DCRNN 類圖時序結構。訓練資料範圍影響學得的節點表示，不能任意換資料或站點次序。

### `airphynet_faithful.py`

定義結合圖卷積、風場資訊與 ODE 狀態演化的 AirPhyNet。`ODEFunc` 是模型持有的可訓練子模組；執行需要 `torchdiffeq`。圖矩陣與風場矩陣會在訓練/推論時計算或傳入模型。

上述 `*_faithful.py` 檔案描述模型結構；資料載入、loss、優化器、驗證與 checkpoint 生命週期主要由相應 `train_*.py` 負責。

## 訓練入口

各訓練程式包含相似的資料管線：依 `split.pkl` 取得時間範圍、建立歷史/預測視窗 Dataset 與 DataLoader、載入圖及 scaler、訓練模型、在 validation split 計算指標，並保存 checkpoint。

| 檔案 | 職責 |
|---|---|
| `train_dcrnn.py` | DCRNN 基本訓練，含 scheduled sampling、驗證和最佳 checkpoint 儲存 |
| `train_dcrnn_demo.py` | DCRNN 訓練示範，增加 TensorBoard、預測圖與可選 W&B 記錄 |
| `train_agcrn.py` | AGCRN 訓練與驗證 |
| `train_gts.py` | 準備節點訓練序列、學圖並訓練 GTS 預測器 |
| `train_airphynet.py` | 傳入地理/風場圖，訓練 AirPhyNet |

常見流程函式包括 `get_loaders()`、`train_one_epoch()`、`evaluate()`、`compute_metrics()` 和 `parse_args()`。不同腳本參數略有差異，執行 `python <script>.py --help` 可確認當前版本。

## 評估與診斷

- `test_models.py`：依 checkpoint 中保存的模型參數重建 DCRNN、AGCRN、GTS 或 AirPhyNet，載入指定資料切分並計算 MAE/RMSE/MAPE；可選擇逐預測時步輸出。
- `test_gts.py`：GTS 專用推論入口。
- `test_extended_horizon.py`：用 DCRNN checkpoint 以較長解碼長度做外推評估。
- `finetune/verify_dataset.py`：檢視延伸資料產物；`finetune/diagnose_seasonal_error.py`：分析季節誤差。

評估時的反標準化使用資料 scaler；因此 scaler、目標特徵位置及資料版本必須與模型訓練相容。MAPE 對接近零的觀測值敏感，解讀時應同看 MAE/RMSE。

## 重要產物與相依關係

| 產物 | 下游用途 | 一致性要求 |
|---|---|---|
| `features.npy` | 模型輸入與目標序列 | 時間、站點、特徵順序固定 |
| `adj_mx.npy` / `adj_wind.npy` | 需要固定圖的模型 | 節點列/欄順序需對應 `stations.csv` |
| `scalers.pkl` | 標準化與反標準化 | 評估必須使用相容統計量 |
| `split.pkl` | train/validation/test 窗口 | 評估報告需說明使用哪個 split |
| checkpoint `.pt` | 模型參數、訓練 args、驗證記錄 | 配套模型、資料和圖版本 |

`checkpoints/`、`checkpoints_yrd/`、`checkpoints_bthsa/` 是不同實驗輸出位置；不能只看檔名判斷兩個 checkpoint 是否同條件。細節應連同其中保存的 `args`、驗證值及相關報告確認。`runs/` 保存 TensorBoard event 檔案。

## Fine-tune 子專案

`finetune/` 透過 `fetch_era5.py`、`fetch_cnemc.py` 取得外部資料，`build_dataset.py` 建置延伸資料，再由 `prepare_finetune_data.py` 對齊模型需要的特徵和 scaler；`finetune_dcrnn.py` 執行微調，`weight_interpolation.py` 支援預訓練與微調權重的插值實驗。各檔案細節、輸入需求及限制見 [`finetune/原始碼說明.md`](finetune/原始碼說明.md)。
