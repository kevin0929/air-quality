# Fine-tune 原始碼說明

## 模型訓練核心

### `finetune_dcrnn.py`

微調主程式。讀取 DCRNN checkpoint、資料切分與 scaler，建立 train/validation/test DataLoader，按 epoch 更新模型，並計算反正規化後的 MAE、RMSE、MAPE。程式會將 TensorBoard scalar 寫入 `runs_finetune/`，把最佳權重及量化報告寫入 `checkpoints_finetune/`。

載入不同站點數的模型時，`load_pretrained_dcrnn()` 會略過站點圖對應的 `supports_stack` buffer，並保留可轉移的可學習權重；其餘不匹配的參數會觸發錯誤。訓練還包含 scheduled sampling、梯度裁切、validation 平滑與 early stopping 等機制，實際參數以 CLI help 和程式為準。

### `dcrnn_faithful.py`

DCRNN 網路架構定義，包含圖擴散卷積、編碼器/解碼器及自迴歸預測。微調程式使用這個模型建立與 checkpoint 相容的網路。

### `weight_interpolation.py`

在預訓練與微調權重間做線性插值，依 validation 指標挑選 alpha，再檢視 test 指標。圖的 `supports_stack` 是資料 buffer，不參與插值。注意目前程式輸出的選模邏輯與報告指標應以原始程式碼版本為準。

## 資料處理與下載

### `prepare_finetune_data.py`

將延伸時段的建置資料轉成 DCRNN 微調程式預期格式，準備 `features.npy`、`adj_mx.npy`、`scalers.pkl`、`split.pkl` 等輸入。使用前須核對特徵和站點順序是否與 checkpoint 相符。

### `fetch_era5.py`、`fetch_cnemc.py`

下載 ERA5 氣象資料與 CNEMC 空氣品質資料。ERA5 下載需 CDS API 憑證；CNEMC 來源與參數見 `config.yaml` 及 `Readme.md`。

### `build_dataset.py`

將原始氣象及空氣品質資料對齊至站點與時間索引，執行插值/缺值處理並產生 `output/` 中的資料集、圖與 metadata。

### `verify_dataset.py`、`diagnose_seasonal_error.py`

前者用於檢查資料集產物；後者分析季節性誤差。可先執行 `python <檔名> --help` 查看命令列選項。

## 設定與產物

- `config.yaml`：日期範圍、站點清單、下載來源、ERA5 特徵、圖距離與缺值策略。
- `stations.csv`：站點 metadata。站點數量和順序需與資料及模型保持一致。
- `checkpoints_finetune/*.pt`：模型 checkpoint；同名 JSON 報告記錄指標和實驗參數。
- `runs_finetune/`：TensorBoard event 檔案，可用 `tensorboard --logdir runs_finetune` 檢視。
- `output/`、`raw/`：建置資料與原始下載檔。

## 重現注意事項

外部資料夾提供了延伸資料 pipeline 的 `output/`，但訓練報告所引用的 `data/processed_yrd_finetune` 並未隨附。因此，現有 checkpoint、報告與 TensorBoard 記錄可直接查閱；若要從頭重跑微調，還需準備對應的 processed data、預訓練 checkpoint 與一致的 scaler/站點索引。
